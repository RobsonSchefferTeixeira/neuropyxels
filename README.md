# NeuroPyxels

NeuroPyxels is a Python-based neuroscience data visualization and quick analysis tool for electrophysiology data, with a focus on Neuropixels recordings.

## Features

- Interactive Neuropixels probe visualization
- Multi-channel electrophysiology trace visualization
- Signal filtering
- Spectrogram visualization
- Phase-amplitude coupling analysis
- Spatial power mapping
- Ripple detection
- Theta epoch detection
- Event visualization and export

## Requirements

Python 3.x
